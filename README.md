# IT Helpdesk Ticket Analysis

## Project Overview
An end-to-end data analytics project focused on IT helpdesk ticket data. The project workflow covers data cleaning with Pandas, SQL-based analysis with MySQL, further analysis using Pandas, and dashboard reporting in Power BI.

## Project Stages
1. **Pandas — Data Import & Cleaning:** inspect data, identify missing values and duplicates, standardize data types, and prepare analysis-ready data.
2. **MySQL — SQL Analysis:** query ticket trends, categories, priorities, teams, and resolution performance.
3. **Pandas — Analysis & Insights:** analyze ticket patterns and summarize operational insights.
4. **Power BI — Dashboard:** present key metrics and trends through report visuals.

## Files Included
- `IT_Helpdesk_Ticket_Analysis.pbix` — Power BI report file.
- `IT_Helpdesk_Ticket_Analysis_Presentation.pptx` — professional project presentation.
- `IT_Helpdesk_40_Professional_Questions.pdf` — the 40 project questions/tasks.

## SLA Assumption
The project question document uses a practice SLA threshold of **24 hours** for resolved tickets with valid resolution-time values. Treat this as a project assumption, not an official service-level policy, unless confirmed by the organization.
